Webデザインの構造解析・デザイントークン抽出
AIプロトタイピングを加速するChrome拡張機能

ネット上の優れたWebサイトから配色・フォント・余白をワンクリックで抽出。AIツール（Claude, ChatGPT, Cursor, v0）と協調し、高品質なモックアップ作成や自社サイトの改善に役立てます。

100% 完全ローカル完結 外部サーバ通信ゼロ MIT オープンソース

各機能の使い道（インスピレーションを形にする）

⚡ 1. モックアップ・プロトタイプ作成用

参考サイトの洗練されたUIレイアウトやカラースキームを瞬時に解析。抽出された DESIGN.md と tokens.json をAIに読み込ませ、「このデザイン体系をベースに新しいランディングページのモックアップを作って」と指示するだけで、完成度の高いワイヤーフレームやコンポーネントが即座に生成されます。

🎨 2. 自身のWebサイトへの適用・改善

「このサイトの余白感やコントラストが美しい」と感じたとき、そのCSSカスタムプロパティやTailwind CSS v4（@theme）トークンを抽出。AIと連携して自身の既存Webサイトのボタンスタイルやタイポグラフィに調和させることで、洗練されたデザインへと素早くブラッシュアップできます。

主要機能（サイドパネルで完結）

🔍 Inspect（要素調査）

ページ上の要素をホバーするだけでボックスモデルや算出CSSをハイライト。ピン留めした要素のCSSを即座にコピー。

💎 Tokens（9ファイル出力）

カラーパレット、フォント、余白、角丸、シャドウを自動解析。Tailwind v4、SCSS、TypeScript型定義、WCAG適合表を一括ZIP出力。

📦 Clone（静的複製）

DOMとスタイルをブラウザ内で収集した静的リファレンスを生成。レスポンシブ幅切り替えビューアー（viewer.html）を同梱。

📚 Library（履歴管理）

生成したトークンパックの履歴をブラウザ内IndexedDBに保存。いつでも再ダウンロードや管理が可能です。

インストール方法（Chrome デベロッパーモード）

本拡張機能はオープンソースとして提供されており、Chromeのデベロッパーモードから直接読み込んでご利用いただけます。

1

リポジトリのクローンまたはダウンロード

git clone https://github.com/nozomicreative/tokotter.git
cd tokotter
2

依存関係のインストールとビルド

npm install
npm run build

※ .output/chrome-mv3 フォルダが生成されます。

3

Chromeのデベロッパーモードで読み込み

Chromeで chrome://extensions を開き、右上の「デベロッパーモード」をONにします。「パッケージ化されていない拡張機能を読み込む」をクリックし、生成された .output/chrome-mv3 フォルダを選択すればインストール完了です。
